# Modalità Volley e Beach Volley

## Modifiche
- Aggiungere un tabellino Volley con set a 25 punti, quinto set a 15, vantaggio di due punti e vittoria al meglio di cinque set.
- Aggiungere un tabellino Beach Volley con set a 21 punti, terzo set a 15, vantaggio di due punti e vittoria al meglio di tre set.
- Aggiornare automaticamente il risultato in set e chiudere la partita quando una squadra raggiunge i set necessari.
- Mostrare per entrambi una classifica dedicata con punti, set vinti/persi e quoziente punti.
- Applicare automaticamente il limite di 6 giocatori per squadra nel Volley e 2 nel Beach Volley.
- Mostrare nel form di creazione le regole corrette quando si sceglie Tennis, Padel, Basket, Volley o Beach Volley.
- Aggiungere le nuove etichette nelle sei lingue esistenti e verificare su telefono.

## Dettagli tecnici
- Salvare set conclusi e punteggio del set corrente insieme alla partita.
- Assegnare in classifica Volley 3 punti per 3-0/3-1, 2 per 3-2 e 1 alla perdente 2-3; Beach Volley 2 punti alla vincente.
- Calcolare il quoziente punti come punti fatti diviso punti subiti, gestendo il caso di zero punti subiti.
